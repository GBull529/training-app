Hybrid Training Tracker – iPhone/Web-App

Diese Version ist als Progressive Web App (PWA) vorbereitet.

Einfachste Nutzung auf dem iPhone:
1. Den gesamten Inhalt dieses ZIP-Ordners auf einen HTTPS-Webhost hochladen.
   Geeignet sind z.B. GitHub Pages, Netlify oder Vercel.
2. Die veröffentlichte URL in Safari auf dem iPhone öffnen.
3. Teilen-Symbol antippen.
4. "Zum Home-Bildschirm" wählen.
5. Danach startet der Tracker fast wie eine normale App.

Wichtig:
- Die Trainingsdaten werden lokal im Browser bzw. in der installierten Web-App gespeichert.
- Ein Backup kann in der App als JSON exportiert werden.
